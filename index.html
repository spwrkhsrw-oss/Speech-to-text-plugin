Revenge plugin

Voice to Text

Turn a recorded voice message into text before sending it. When you send a voice message, the plugin asks whether you want to send the original audio or a transcript.

How to use it View source on GitHub

What it does

When the plugin detects a voice message being sent, it offers three choices: send it as voice, send it as text, or cancel. If you choose text, it asks an AI transcription provider to turn the audio into written words.

The plugin needs a Gemini or OpenRouter API key configured in its settings before transcription can work.

Install in Revenge

  1. Make sure GitHub Pages is enabled for this repository: open Settings → Pages.
  2. Under Build and deployment, choose Deploy from a branch, select main and /(root), then save.
  3. Wait for GitHub Pages to publish the site.
  4. In Revenge, open Settings → Plugins, tap +, and paste the install URL shown below.
https://spwrkhsrw-oss.github.io/Speech-to-text-plugin/

Use the plugin URL above in Revenge. The #using-speech-to-text part is only a shortcut that jumps to the instructions on this webpage; it is not part of the install URL.

After publishing, you can check that the plugin manifest is online here: open manifest.json.

Using Voice to Text

  1. Open Discord with Revenge, then go to Settings → Plugins.
  2. Find Voice to Text and open its settings using the gear icon.
  3. Choose either Gemini or OpenRouter, then enter the API key for that provider.
  4. Record a voice message and send it. When the plugin asks what to do, choose Send as text to transcribe it, or Send as voice to send the original audio.

Privacy note: If you choose “Send as text,” the audio is sent to the AI provider you configured so it can create the transcript. Review that provider’s privacy terms before using it.

If it doesn't work

First, open the manifest link above in your browser. If it shows JSON, GitHub Pages is serving the manifest. If it shows a 404 or an error, check the Pages settings and make sure manifest.json, index.js, and this index.html file are all in the repository's root folder.

If the plugin installs but transcription fails, check that the API key is correct and that your selected provider/model is available to your account.
